# 约一万二千字短篇小说 skill

## 文件

- `SKILL.md`：主规则与完整执行流程。
- `references/templates.md`：需求、人物、背景、导语、大纲、场景和连续性模板。
- `references/review-checklist.md`：因果、人物、结构、语言及交付检查。
- `references/sample-a.md`：A 方案样板策划，含五个书名、三版导语、人物背景、15 场大纲及伏笔。

## 使用

在支持本地 skill 的工具中，将整个 `short-story-12000` 文件夹放入该工具支持的 skills 目录，保留相对路径。不同工具的目录和启用方式不同，本仓库已将此技能放置于 `.agents/skills/short-story-12000/`；是否自动发现取决于客户端，必要时重新打开会话。

也可以直接提供 `SKILL.md` 和所需配套文件给写作助手，要求按其中流程执行。

示例请求：“按 short-story-12000，为我策划一篇现实复仇短篇。采用样板 A，先给导语和详细大纲，确认后再写正文。”

## 已确认默认偏好

现实复仇／逆袭，可切换类型；A 为首个样板；一路反杀，结尾保留苦涩。约 12,000 字，五段式；超过 1000 字的单次交付须创建 Markdown 文档，聊天只给摘要与文件链接。正文不会在制作 skill 时自动生成。

## 检查范围

本包执行文件存在、引用路径、结构与场景预算检查。尚未生成小说正文，未验证跨平台自动加载，也未完成样板具体法律事项核查。待核查事项已在样板列出。
