# 设计系统
所有视觉 token 集中在 design-spec.json：背景、主色、强调色、正文色、字体、比例、边距。每次新参考重新定义，不固定为本例。
课堂基线：标题 32–44 pt，正文 24–28 pt，注释通常不低于 16 pt；投影前按教室环境调节。正文留足行距，单页优先一个主旨；不要靠缩小字体容纳长文。
安全边距至少 0.5 英寸；正文避免铺满画布。内容区使用高对比纯色纸片，纹理与格纹置于边缘或低信息区域。
封面/章节可大插画；正文轻纹理；数据页装饰更少。中文标题可用可用且授权明确的手写字体；没有则使用清晰替代并报告。不可宣称示例的 Noto Serif 为手写字体。
全局一致性包括图标线宽、圆角、阴影、强调样式、页码和导航位置。正文、图表、基础形状用原生对象；复杂绘画可栅格化，且避免压平整页。
