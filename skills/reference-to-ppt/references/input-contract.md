# 输入契约
必需：参考图片或可编辑 PPT 模板、演示内容。可选：受众、课程目标、演讲时长、页数、WPS 版本及系统、素材授权、学校标识、公式与视频需求、引用格式。
默认：中文、16:9、课堂、适度编辑。缺少受众等信息可提出明确假设；内容和参考都缺失时不得伪造完成。
PPT 模板输入应保留副本；提取主题色、字体、母版、尺寸和代表布局。图片输入先目视分析再抽样取色，避免将截图外框当作母版。
JSON 至少包含 title、palette、fonts、slides。每页 type、title、body（字符串列表）、notes；chart 页另含 categories、values、source。未知页型或缺失图表数据必须报错。
