# 动画、切换与交互
分别记录页内动画、跨页切换、点击导航。默认手动翻页，无声音与自动循环。装饰不持续运动。
本版生成器：写入基础 fade 页面切换；目录支持页内链接；process 页可配置 reveal=true，生成连续累计步骤页，用手动翻页实现可靠揭示。它不是 WPS 原生对象级时间轴动画。
每个步骤写入备注和 motion-script.md。源文件中未写入的动画不能报告已实现。跨页形变、复杂移动和点击触发须在支持的编辑器中实际制作并验证；否则提供连续页方案且标明差异。
静态版/PDF 保留最终内容；揭示系列会占用多张物理页，报告内容页与物理页数量。跳转目标按内容页映射，避免展开后错链。
