# WPS 兼容
交付 .pptx；提供可复用 .potx。模板有主题字体与母版，但示例复用页以复制现有页面为主，不宣称含全部自定义母版布局。
记录 WPS 版本、系统、字体、屏幕比例。字体不默认嵌入，不附带未获许可的字体文件。中文回退优先 Noto Sans CJK SC / 思源黑体，实际需在使用机器安装或替换。
尽量用基础形状、原生文本、原生图表、内部超链接和 fade。复杂效果必须逐项验证。LibreOffice 渲染只能证明该渲染器中的表现，不能证明 WPS 一致。
验收操作：用目标 WPS 打开→检查字体与分页→进入放映→逐次点击揭示→验证目录跳转→检查图表可编辑→保存重开。没有目标软件时所有 WPS 项标“未验证”。
